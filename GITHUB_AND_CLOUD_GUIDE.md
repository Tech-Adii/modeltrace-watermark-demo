# Share ModelTrace on GitHub + a public Streamlit website

This is an add-on to the **existing** `D:\model-extraction-watermark` project. It does not include trained model weights, your watermark secret, or copyrighted data. Keep your original files.

## 1. Prepare the folder

Copy `cloud_app.py`, `requirements.txt`, and `.gitignore` into the **root** of your existing `D:\model-extraction-watermark` folder.

Before publishing, ensure these files exist:

- `model.py` (from your original project)
- `phone_model.py`
- `phone_watermark.py`
- `models/phone_original.pt`
- `models/phone_copied.pt`
- `demo_samples/sandal_clean.png`
- `demo_samples/sandal_watermarked.png`
- `cloud_app.py`
- `requirements.txt`

The two `.pt` files and two sample images are generated by `train_phone_original.py` and `train_phone_copy.py`. If these files don't exist, train first.

**Caution:** The provided `.gitignore` intentionally makes the two demo checkpoints and demo sample PNGs shareable on GitHub. Public model weights and the publicly shown watermark patch are *not* secret. This is suitable for a classroom demonstration but not a secure ownership watermark. Keep your real ownership experiment in a private repository and/or a private backend.

Do **not** upload the `private/` directory or `private/phone_demo_secret.json`. Do **not** upload your `venv/`, data directory, or unrelated checkpoints.

## 2. Install Git

Download from https://git-scm.com/downloads and complete installation. Close and reopen VS Code; in the VS Code Terminal:

```powershell
git --version
cd D:\model-extraction-watermark
```

## 3. Create a GitHub repository

Sign into GitHub: https://github.com/new

Create a **Public** repository such as `modeltrace-watermark-demo`, leaving README / license / .gitignore **unchecked** for an empty remote.

## 4. Push safely

In the VS Code PowerShell terminal:

```powershell
git init
git branch -M main
git add .
git status
```

**Inspect `git status` before committing**. You should see the desired source files, the two `.pt` checkpoints, and the two demo sample PNGs — but **NOT** `venv/`, `private/`, `data/`, or `.streamlit/secrets.toml`. If secret files appear, stop and fix `.gitignore` before committing.

Then:

```powershell
git commit -m "Share ModelTrace two-model watermark demo"
git remote add origin https://github.com/YOUR_USERNAME/modeltrace-watermark-demo.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username. GitHub may ask you to authenticate in your browser. If Git is already initialized, skip `git init`; if `origin` exists, use `git remote set-url origin URL` instead. Individual GitHub files larger than 100 MiB cannot be added normally; use Git LFS or private artifact hosting if necessary.

## 5. Share code

Send your repository URL to friends:

`https://github.com/YOUR_USERNAME/modeltrace-watermark-demo`

This lets them download/clone source and checkpoints. GitHub does **not** host your live Python processes and `127.0.0.1` URLs never work on a friend's machine.

## 6. Deploy the web app

Open https://share.streamlit.io/ and sign in with GitHub.

- Choose **Create app** → deploy from an existing GitHub repo.
- Select repo `modeltrace-watermark-demo`, branch `main`, and entrypoint **`cloud_app.py`**.
- In Advanced settings, choose a supported Python version such as **3.12**, if offered.
- Add a server-side deployment secret using this TOML syntax (do not commit it):

```toml
PHONE_DEMO_SEED = "PASTE_SEED_FROM_YOUR_OWN_FILE_HERE"
```

The value is the number inside your existing local `private/phone_demo_secret.json`, under `seed`. **Do not create a new seed**; the original trained models must use the same seed. This is a *demonstration* watermark because the public example reveals the pattern's behavior.

Deploy. The cloud app uses `torch.load(..., weights_only=True)` and loads each model in memory. It does not require local API ports and it does not run `START_DEMO.py`.

## 7. Send these THREE links

When deployed, your app will have a URL similar to `https://YOUR-APP.streamlit.app`.

Open three browser windows/tabs:

- Original AI: `https://YOUR-APP.streamlit.app/?view=original`
- Copied AI: `https://YOUR-APP.streamlit.app/?view=copied`
- Detection: `https://YOUR-APP.streamlit.app/?view=detect`

Share these links with classmates or your mentor. Everyone can interact with both trained AI models without installing Python. You can test the public site in a private/incognito browser window.

## 8. Local test before deployment

```powershell
python -m pip install -r requirements.txt
python -m streamlit run cloud_app.py
```

The app displays a local address. You can add `?view=copied` or `?view=detect` to switch windows. Locally, the detector reads your existing `private/phone_demo_secret.json` if no cloud secret is present.

## Troubleshooting

- **Missing model files:** Verify that `models/phone_original.pt` and `models/phone_copied.pt` were created by training and actually committed (unless you intentionally host checkpoints privately).
- **Missing sample images:** Verify `demo_samples/sandal_clean.png` and `demo_samples/sandal_watermarked.png` are in GitHub.
- **Detection says missing seed:** Set `PHONE_DEMO_SEED` in the Streamlit app's Secrets settings. Keep this out of GitHub.
- **Torch install fails:** Select Python 3.12 in Streamlit deployment Advanced settings and review cloud build logs; check torch/torchvision compatibility.
- **Need genuine secret watermark ownership proof:** Do not publish weights, triggers, or a downloadable copy of the secret. This public educational demo cannot establish that level of secrecy.
